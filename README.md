# DIGITAL GHOST TOWN

An atmospheric zero-budget browser game built with vanilla HTML, CSS and JavaScript.

SRI LANKA / 03:17 AM

You found an abandoned town on the internet.

Explore the locations. Read the fragments. Find the objects. Open House 17.

## Features

- Mobile responsive interface
- Touch friendly controls
- Keyboard support
- Local save using localStorage
- Inventory
- Puzzles
- Multiple story locations
- CRT, rain and VHS style effects
- No framework
- No API
- No backend
- GitHub Pages ready

## Run

Open index.html locally, or enable GitHub Pages from Settings > Pages and deploy the main branch.
